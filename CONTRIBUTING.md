# Contributing

Thank you for contributing to Basketball Scoresheet Parser.

## Workflow

1. Fork the repository.
2. Create a descriptive branch.
3. Implement changes and tests when applicable.
4. Open a Pull Request.

## Branch Naming

Use names such as `feature/new-parser`, `fix/validation`, or `docs/update-guide`.

## Commits

Prefer clear prefixes:

- `feat:` features
- `fix:` fixes
- `docs:` documentation
- `test:` tests

## Pull Requests

Include the motivation, changes, validation performed, and relevant examples.

## Contributions

Code, documentation, testing, datasets, examples, and issue discussions are welcome.
